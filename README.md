# iMagellan

Live passage briefing. Windy-style wind, atlas tidal streams, GPS.
First route: St Peter Port → Les Sablons.

**Not a chart. Plotter stays primary.**

Repo: https://github.com/MonkeyScience/iMagellan

## DigitalOcean App Platform
1. Create App → GitHub → `MonkeyScience/iMagellan` → `main`
2. Resource type: **Static Site**
3. Index: `index.html` · output `/`
4. App name: `imagellan`
5. Deploy → open the `*.ondigitalocean.app` URL in Chrome → Add to Home screen

Older repos `channel-pass` and `spp-sablons` can be archived later.
